# Chat Review (챗 리뷰) - SillyTavern 확장

AI 답변에 👍/👎, 별점(1~5), 이유를 남기고, **평가한 메시지에만** AI가 볼 수 있는 표시를 붙입니다. 평가 안 한 메시지는 토큰이 늘지 않아요.

## 설치
1. 이 폴더(`st-chat-review`)를 아래 중 한 곳에 넣습니다.
   - `SillyTavern/data/<사용자 폴더>/extensions/` (보통 `default-user`)
   - 또는 `SillyTavern/public/scripts/extensions/third-party/`
2. 실리태번을 새로고침(F5)합니다.
3. 확장(Extensions) 패널에서 **Chat Review**가 보이면 성공이에요.

## 사용법
- AI 메시지의 버튼 줄에 ⭐ 버튼이 생깁니다. 누르면 평가 창이 열려요.
- 저장 범위: 이 채팅만 / 이 캐릭터 / 전체 공통
- 평가한 메시지는 이름 옆에 작은 배지(예: 👍 ★4)가 표시됩니다.
- 설정 패널에서 개수, 글자수, 포함할 평가(좋아요만 등)를 조절하고, "평가 기록 보기 / 삭제"에서 기록을 관리합니다.

## AI가 보는 내용 (영어)
- 이 채팅의 평가한 메시지 끝에: `[User's review of this reply: liked, 4/5 — reason: "..."]`
- 캐릭터/전체 범위 평가는 다른 채팅에서 "Past feedback..." 노트 한 덩어리로 들어갑니다.

## 알아둘 점
- 그룹 채팅에서는 "이 캐릭터" 범위를 쓸 수 없어요.
- 스와이프한 메시지는 각 답변에 평가가 따로 붙습니다.
- 메시지를 지워도 캐릭터/전체 노트는 남아요. 설정의 "평가 기록"에서 지울 수 있습니다.
- 이 확장은 JavaScript를 실행합니다. 출처를 모르는 확장은 설치하지 마세요.
